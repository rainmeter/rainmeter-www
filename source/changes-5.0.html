Rainmeter 5.0 #

Rainmeter 5.0 is our biggest release in years, packed with new features and optimizations. From crisp skins on high-DPI displays and a refreshed dark mode interface to faster performance and more powerful tools for skin authors, there's something for everyone.

Download Rainmeter 5.0 RC1

October 12, 2026

Highlights #

🔍 High-DPI support and skin zoom: Skins now look crisp on high-DPI displays, including 4K monitors. You can also zoom each skin to make it smaller or larger. See Scaling and zoom details.

🌙 Dark mode UI: Rainmeter’s dialogs, context menus, and skin tooltips now follow Windows dark mode.

⚡ Performance: Rainmeter now runs faster and uses memory more efficiently. Depending on your skins, you may see much lower CPU, GPU, and memory usage.

💤 Optimized invisible skin updates: Rainmeter now skips drawing skins that are hidden from view. Skin authors can save even more resources by updating hidden skins less often. See details.

🐛 New Debug dialog: The new Debug dialog lets you inspect skins, watch expressions, and check display and network details. It can also refresh skins automatically when their files change. See details.

🛠️ More tools for skin authors: Add editable text fields with the new TextEdit meter and scalable vector images with the new SVG meter. Other additions include built-in versions of bundled plugins, JSON support in WebParser, Lua Unicode functions, and more commands to control skins, meters, and measures.

Changes in Rainmeter 5.0 #

Find more details and examples in the manual and the Rainmeter 5.0 announcements.

Compatibility and installation #

  • ChangedSystem requirements: Rainmeter now requires 64-bit Windows 10 (version 1903 or later) or Windows 11. 32-bit Windows and older Windows versions are no longer supported.
  • FixedInstaller: The installer now works better with Windows Smart App Control.

Scaling, zoom, and arranging skins #

  • AddedHigh-DPI scaling: Skins now follow each monitor’s DPI scaling. They redraw at the right size when you move them between monitors or change your display settings. See Scale and Zoom.
  • AddedSkin zoom: You can now zoom each skin from 10% to 500% using the skin context menu, Manage's Skins tab, or the skin's Zoom setting in Rainmeter.ini. See Scale and Zoom.
  • AddedDefault zoom: You can now set a Default zoom in Manage’s Settings tab. Enable Force to apply it to all skins and prevent individual zoom changes. These settings use DefaultZoom and ForceDefaultZoom in Rainmeter.ini.
  • AddedMultiple skin selection: You can now select several skins by holding CTRL-ALT and clicking them. Move them together, drag their edges or corners to resize them, or change their settings through a shared context menu. See Arranging Skins.
  • AddedDisplay changes: The OnDisplayMetricsChange action now runs when any display’s layout, resolution, or scaling changes.
  • ChangedCoordinates: Skin layouts and built-in position and size values now use logical coordinates to account for DPI scaling. New variables let you read physical pixel values and zoomed sizes too. See Skin variables.

Variables, formulas, and skin options #

  • AddedSkin variables: New [$Skin...] variables let you read a skin’s position and size, including physical pixel values and zoomed sizes. They also provide its DPI factor, zoom factor, z-position, and visibility. See Skin variables.
  • AddedDisplay variables: New [$Display...] and [$DisplayDevice...] variables let you read monitor and device details. These include positions, sizes, work areas, physical coordinates, virtual screen bounds, DPI factors, names, numbers, and counts. Leave out the number to use the display that contains most of the skin, or add a number to choose a specific display or device. See Monitor variables.
  • AddedEnvironment variables: You can now use Windows environment variables with [%VariableName].
  • AddedOption inheritance: Meters and measures can now use @Inherit to reuse options from other sections. It works like MeterStyle, with support for measures too. See Option inheritance.
  • AddedFormulas: Measure names and $Skin... and $Display... variables can now be used without brackets in formulas throughout skins.
  • AddedInvisible updates: The Update option now lets you set a separate update interval for hidden skins, such as Update=1000 | Invisible 10000. Invisible 0 pauses regular updates while the skin is hidden. Refreshing the skin or using !Update still updates it. See Invisible updates.
  • ChangedText file encoding: Rainmeter now fully supports UTF-8 skin and configuration files.
  • AddedSyntax version: Skin authors can now opt into SyntaxVersion=2 in the Rainmeter section. This enables accurate text rendering and leaves %VariableName% text unchanged; use [%VariableName] for environment variables. It also disables the deprecated Image meter Path option, WebParser ForceReload option, and Lua GetStringValue() and automatic PROPERTIES table. Version 1 remains the default. Unsupported syntax versions are rejected.
  • AddedRequired version: AppVersion now accepts version strings such as 5.0.0 or 5.0.0.5291, so skins can require a specific revision. Existing packed integer values still work.

Meters and images #

  • AddedTextEdit meter: Meter=TextEdit now lets you add editable text fields to a skin. It supports single-line and multiline input, selection, copy and paste, undo, scrolling, placeholders, password masking, input filtering, and read-only mode. Actions can read the text with [$Input] and captured regular expression matches with [$Input:MatchN].
  • AddedTextEdit bangs: You can now control input fields with !TextEdit:Focus, :Dismiss, :Submit, :Select, :SelectAll, :SetText, :Clear, :Reset, :ScrollByLine, and :ResetScroll.
  • AddedSVG meter: Meter=SVG now displays SVG files or inline SVG code. Use Attribute, Attribute2, and so on to change element attributes. You can target an element by ID, the root svg element, or every element with *.
  • AddedString meter: You can now align text to both edges with StringAlign=Justify.
  • AddedLine meter: LineJoin now lets you choose how line segments join.
  • FixedTransformationMatrix: Removing this option or leaving it empty now clears the meter’s previous transformation.
  • ChangedGraphics recovery: Skins can now recover and resume drawing after losing access to the graphics device.
  • ChangedShape errors: Errors and warnings now show which Shape option caused the problem.

Measures #

  • ChangedBuilt-in measures: ActionTimer, AdvancedCPU, AudioLevel, CoreTemp, FileView, FolderInfo, InputText, iTunes, PerfMon, Ping, Power, Quote, ResMon, RunCommand, SpeedFan, UsageMonitor, WindowMessage, and Audio (formerly Win7Audio) are now built-in measures. You can still use the existing Measure=Plugin syntax.
  • AddedDragDrop measure: The Drag&Drop plugin is now built in as Measure=DragDrop. The existing plugin syntax still works. The FancyRenderer option has been removed.
  • AddedMouse measure: Measure=Mouse is now built in, with support for mouse coordinates and actions.
  • AddedMouse click capture: You can now use !Mouse:StartCapture to capture the next click on any monitor. It runs the matching button-up action with the click position in $MouseX$ and $MouseY$. Press Escape or use !Mouse:StopCapture to cancel. Set the overlay color with CaptureOverlayColor and its system cursor with CaptureOverlayCursorName.
  • AddedWebParser JSON: JsonPointer now lets you read values from JSON responses without a regular expression. Child measures can select values within their parent’s selected JSON node. Use JsonPointer=1 to enable JSON parsing without selecting a value.
  • AddedWebParser commands: !WebParser:Refetch and !WebParser:ClearResults now let you fetch fresh data or clear the parsed results.
  • ChangedWebParser encoding: WebParser now detects the text encoding of local file:// URLs, including UTF-8 and UTF-16, when using the default CodePage=0.
  • ChangedQuote encoding: The Quote measure now detects text file encoding automatically, including UTF-8 and UTF-16.
  • AddedLocale-formatted numbers: String, Registry, and WebParser measures can now use NumberConversionFormat=Locale to read numbers in your Windows regional format. For example, 1.234,56 can be read as 1234.56.
  • AddedTime measure: TimeStampFormat now supports ordinal dates, week-number dates, ISO week dates, and the %F, %g, %G, %u, %V, %z, and %Z codes. Time-zone offsets now convert timestamps to UTC. %c, %x, and %X use the selected Windows regional format. Supported modifiers are now handled, and invalid or conflicting input produces an error.
  • AddedFileView filtering: ExcludeExtensions now lets you hide files with the listed extensions. If you also set Extensions, that setting takes priority.
  • AddedFileView commands: IndexUp and IndexDown now accept a step count so you can move several entries at once.
  • AddedUsageMonitor: You can now use Index=Count to count instances, Index=Sum for totals, and Index=Average for averages. Process V2 instances can now be grouped by process name. The first collected value is now returned before UpdateDivider takes effect.
  • AddedAudioLevel: OnAudioStartAction and OnAudioEndAction now run when audio playback starts or ends. Skins can use these actions to change how often they update during playback. Disabling the measure stops audio monitoring and these actions.
  • FixedAudioLevel: AudioLevel now reinitializes when the default audio device changes. USB speakers no longer prevent automatic sleep.
  • AddedNowPlaying covers: NowPlaying now supports local .webp and .avif covers, plus covers embedded in Ogg Vorbis files.
  • AddedNowPlaying commands: New !NowPlaying: bangs let you control playback and the player, including position, rating, volume, shuffle, and repeat.
  • FixedRecycleManager: Rainmeter no longer freezes while emptying a large recycle bin.
  • ChangedRunCommand: Stopping a command now also stops any processes it started, including their child processes.
  • ChangedWiFiStatus: Where Windows supports it, WiFiStatus now checks connection quality and speed without repeatedly requesting location access. This also keeps the Windows capability access log from growing too large.
  • AddedWindows media players: NowPlaying can now use PlayerName=Windows to read track details and control the current Windows media session. This works with apps that publish Windows media controls, including Spotify and supported browser players. Available track details and controls depend on the app. File, year, rating, volume, and commands to open or close the player are not supported.
  • ChangedSpotify: PlayerName=Spotify now uses the same Windows media session as PlayerName=Windows. That session may belong to another app. OpenPlayer, ClosePlayer, and TogglePlayer no longer launch or close Spotify.

Bangs and command line arguments #

  • AddedZoom bangs: !SetZoomFactor now lets you change a skin’s zoom. Use 1.25 for 125%, or Default to restore the default zoom.
  • AddedUpdate interval: !SetUpdate now lets you change how often a visible skin updates. It leaves the hidden skin update interval unchanged.
  • AddedVisibility override: You can now use !ForceEnableVisibleMode to keep a skin updating and drawing even when it is hidden from view.
  • AddedMeasure groups: !CommandMeasureGroup now lets you send a command to all measures in a group.
  • AddedDebug dialog: !Debug now opens the Debug dialog. You can choose Log, Display, Network, Plugins, or Skin with an optional parameter. For Skin, you can also specify a config name.
  • AddedRestart: You can now restart Rainmeter with !Restart or Rainmeter.exe /Restart. The latter replaces RestartRainmeter.exe, but existing skin actions that use RestartRainmeter.exe still work. See !Restart.
  • AddedLaunch before executing bangs: You can now use Rainmeter.exe [!Launch][!Bang][!Bang2] to start Rainmeter if needed, then run the bangs. See !Launch.
  • AddedSkin bang namespace: !Skin:Load, !Skin:Unload, !Skin:Toggle, and !Skin:Edit are now aliases for the existing config commands. Use [!Skin:Unload *] to unload all skins. With the !Skin: prefix, bangs that accept a skin target can now put that target first.
  • AddedMeter and measure bangs: New !TextEdit:, !WebParser:, !NowPlaying:, and !Mouse: commands let you control these meters and measures. Section commands can now target a group with Group=GroupName. You can also leave out the section selector when running a command from a matching section’s action.
  • ChangedSetOption: You can now leave out the section argument of !SetOption to change an option in the current section.
  • ChangedActivating skins: Activating a loaded skin now brings it in front of other windows at the same z-position. Activating an active config or deactivating an inactive one no longer produces unnecessary warnings.
  • AddedGroup selectors: Skin and meter selectors can now match several groups. Use Group=a|b to match either group, or Group=a&b to require both. A selector cannot mix | and &.
  • AddedMedia keys: !SendKey now lets you send MediaNextTrack, MediaPrevTrack, MediaStop, MediaPlayPause, VolumeMute, VolumeDown, and VolumeUp. It replaces the now deprecated MediaKey measure.
  • AddedAudio measure bangs: New !Audio:SetVolume, !Audio:SetOutputIndex, !Audio:Mute, !Audio:Unmute, and !Audio:ToggleMute bangs let you control volume, output devices, and mute state.
  • AddedActionTimer measure bangs: You can now start and stop action lists with !ActionTimer:Execute and !ActionTimer:Stop.
  • AddedLoop measure bang: !Loop:Reset now lets you reset a Loop measure.
  • AddedRecycleManage measure bangs: You can now empty the recycle bin with !RecycleManager:EmptyBin or !RecycleManager:EmptyBinSilent, and open it with !RecycleManager:OpenBin.
  • AddedRunCommand measure bangs: You can now run, close, or terminate a command with !RunCommand:Run, !RunCommand:Close, and !RunCommand:Kill.
  • AddedWindowMessage measure bang: !WindowMessage:Send now lets you send a message through a WindowMessage measure.

Lua scripting and plugin support #

  • ChangedLua scripting: Lua scripts now use LuaJIT for faster performance.
  • AddedSetting options and variables: SKIN:SetOption, SKIN:SetOptionGroup, and SKIN:SetVariable now let you set options or variables directly. Pass a table to set several name/value pairs at once. Meter and measure objects now support SetOption too.
  • AddedUnicode strings: Unicode scripts now have uc string functions for matching, replacing text, measuring length, slicing, changing case, reversing, and converting codepoints. Scripts saved with a UTF-8 BOM are now recognized as Unicode scripts, alongside UTF-16 scripts.
  • AddedText files: SKIN:ReadTextFile and SKIN:WriteTextFile now let you read and write text files with Unicode conversion. WriteTextFile uses UTF-8 by default.
  • ChangedSkin position: SKIN:GetX() and SKIN:GetY() now return logical coordinates.
  • FixedMeter dimensions: Changes made with Lua meter SetW() and SetH() now persist, just like SetX and SetY. Text is remeasured when needed.
  • FixedScript errors: Failed Lua callbacks no longer cause memory corruption or crashes. Errors from callbacks and !CommandMeasure are now clearer. Custom function calls and dofile are also handled correctly.
  • AddedPlugin API: Plugins can now read a skin’s effective scale, DPI scale, zoom scale, transparency, click-through state, and draggable state. HandleSkinSettingChange now notifies plugins when these settings change. Plugin position, size, and font-size options now support scaling too.

User interface and recovery #

  • ChangedAbout and Debug: Version information now has its own About dialog. The new Debug dialog has Log, Skins, Plugins, Display, and Network tabs. Manage and Debug now remember their window sizes.
  • AddedDebug Skins tab: You can now use watches to evaluate expressions and run actions. You can also filter measures and variables, or jump to a meter or measure in the skin file. Add a value to watches by double-clicking it or using its context menu.
  • AddedRefresh on file change: The Debug Skins tab can now automatically refresh the selected skin when its INI file, included files, or Lua scripts change. Press CTRL-R or F5 to refresh the selected skin manually. Automatic refresh turns off if files change too often in a short time.
  • AddedDebug Display and Network tabs: The new Display tab shows monitor positions, sizes, and scaling. The new Network tab lists network interfaces, with an option to include virtual ones. You can copy Log, Display, and Network entries individually or all at once.
  • ChangedLogging: The in-memory log now keeps 50 entries instead of 20. Logging controls and log-file commands are now in the Debug dialog.
  • ChangedTray icon: Clicking the tray icon now opens Manage. CTRL-click opens Debug. Launching Rainmeter.exe when Rainmeter is already running now opens Manage too.
  • ChangedUpdate checks: Rainmeter now checks for updates five minutes after startup, then once a day.
  • AddedContext menu shortcuts: Holding Shift now changes Exit to Restart in the Rainmeter context menu, and Refresh skin to Focus skin in a skin context menu. Focus skin brings the skin to the front within its current z-position. Skin menus now also include Debug skin.
  • RemovedContext menus: The Game Mode and Logging submenus have been removed from the Rainmeter context menu. You can still find Game Mode in Manage and logging controls in Debug.
  • AddedSkin discovery: Changes to the Skins folder are now detected automatically. Rainmeter refreshes the skin list when you open a context menu or switch to Manage. It also checks for new skins when you activate a config.
  • ChangedDialogs: Dialogs now look sharp on high-DPI displays and are positioned correctly across monitors. File and folder browsing now uses modern Windows dialogs. The application, installer, and skin tree also have updated icons.
  • AddedCrash dumps: Crash dumps are now saved in Crashes\ under the Rainmeter settings folder. You can include these files when reporting a crash. Dumps older than one week are removed automatically.
  • AddedSafe Start recovery: If Rainmeter crashes twice within five minutes, it now offers to start in Safe Start mode. You can also enter Safe Start by holding CTRL-SHIFT for one second during startup.
  • ChangedTranslations: The Skin Packager and Skin Installer dialogs are now translatable.
  • ChangedDebug icons: The Debug log now uses updated icons.

Skin Packager #

  • AddedLoad previous: You can now reuse the settings from the last time you packaged a skin. These include its name, author, layouts, plugins, header image, and output folder. Hold Shift to delete an entry from the menu. See Skin Packager.
  • AddedPlugin selection: Selecting a plugin DLL now also looks for the matching DLL for the other architecture. It checks corresponding folders, such as 32bit and 64bit.
  • AddedBack button: You can now return to the previous packaging step without starting over.
  • ChangedPackage options: The minimum Windows version option has been removed. Component dialogs are now wider and show plugin paths more clearly. File browsers now open at the current selection.

Other fixes #

  • FixedMeasures: Fixed issues that could freeze or crash Rainmeter when using WebParser, NowPlaying, or RecycleManager.
  • FixedContainers: An empty Container value no longer selects an unnamed meter and accidentally clips other meters.
  • FixedSkin fading: Refreshing a skin during a fade no longer leaves it partially transparent. Starting a new fade while one is already running no longer makes the fade jump to its end value.
