Rainmeter 5.0 #

The following are the user-facing changes in Rainmeter 5.0 since Rainmeter 4.5.26 (revision 3894).

Highlights #

High-DPI support and skin zoom: Skins render at each monitor's display scale and resize when moved between monitors. Zoom individual skins, set a default zoom, or select several skins with CTRL-ALT to move and resize them together. Scaling and zoom details.

TextEdit meter: Add editable text fields directly to skins, with single-line or multiline input, selection, clipboard support, input filtering, and password masking. Meter details.

SVG meter: Display scalable vector images from files or inline SVG code, and change element attributes dynamically. Meter details.

New Debug dialog: Inspect skins, watch expressions, view display and network information, and automatically refresh skins when their files change. Interface details.

More tools for skin authors: Built-in replacements for bundled plugins, JSON parsing in WebParser, Lua Unicode functions, and new commands for controlling skins, meters, and measures. Measure details and Lua details.

Invisible skin updates: Give obscured skins a slower update interval or suspend their regular updates while invisible. Skin option details.

Updated skin syntax: Opt in with SyntaxVersion=2 for accurate text rendering and explicit environment-variable expansion. Existing skins retain the default version 1 behavior. Compatibility details.

Windows requirements: Rainmeter 5.0 requires 64-bit Windows 10 version 1903 or later, or Windows 11. Older Windows versions and 32-bit systems are no longer supported. System requirements.

This overview reflects the source changes through October 6, 2026. Entries describe differences between the tagged release and this version of master.

Changes in Rainmeter 5.0 #

Additional details and examples can be found in the manual and the Rainmeter 5.0 announcements.

Compatibility and installation #

  • ChangedSystem requirements: Rainmeter requires 64-bit Windows 10 version 1903 or later, or Windows 11. Support for 32-bit Windows and older Windows versions has been removed.
  • AddedSkin syntax: SyntaxVersion=2 in the skin's [Rainmeter] section opts into updated syntax behavior. It always enables AccurateText=1 and leaves environment variables such as %USERNAME% literal. Use [%USERNAME] to expand them instead. The default syntax version remains 1 for existing skins.
  • RemovedLegacy syntax in version 2: Skins using SyntaxVersion=2 no longer support the Image meter's legacy Path option, WebParser's ForceReload option, Lua's GetStringValue() callback, or the automatic Lua PROPERTIES table. Skins requiring a syntax version newer than Rainmeter supports display an error instead of loading.
  • ChangedInstaller: Improved rendering on high-DPI displays, updated the artwork, and included the version on the welcome page. Portable installations remember the chosen installation folder and preserve an existing Rainmeter.ini.
  • ChangedStartup: The start-with-Windows setting uses a Windows startup registry entry instead of a Startup folder shortcut.
  • ChangedSkin packages: Rainmeter repairs the .rmskin file association on startup. Packages appear as Rainmeter Skin Package in File Explorer.
  • FixedInstaller: Improved compatibility with Windows Smart App Control, corrected handling of installation paths, and fixed quoting of the Skin Installer command for paths containing spaces.

Scaling, zoom, and arranging skins #

  • AddedMonitor scaling: Skins follow each monitor's DPI scaling and redraw at the appropriate size when moved between monitors or when display settings change. See Scale and Zoom.
  • AddedSkin zoom: Zoom individual skins from 10% to 500% using the skin context menu, Manage's Skins tab, or the skin's Zoom setting in Rainmeter.ini.
  • AddedDefault zoom: Manage's Settings tab includes Default zoom and Force. These correspond to DefaultZoom and ForceDefaultZoom in Rainmeter.ini. Force applies the default zoom to all skins and prevents individual zoom changes.
  • AddedMultiple skin selection: Hold CTRL-ALT and click to select skins. Selected skins can be moved, resized by dragging their edges or corners, and adjusted together through a shared context menu. See Arranging Skins.
  • AddedDisplay changes: The OnDisplayMetricsChange action runs when any display's layout, resolution, or scaling changes.
  • ChangedCoordinates: Skin layout and built-in coordinate and size values use logical coordinates for DPI scaling. New physical and zoomed size variables provide the corresponding pixel and zoomed values.

Variables, formulas, and skin options #

  • AddedSkin variables: New [$Skin...] variables provide position, size, physical position and size, zoomed size, DPI factor, zoom factor, z-position, and visibility. See Skin variables.
  • AddedDisplay variables: New [$Display...] and [$DisplayDevice...] variables provide monitor and device geometry, work areas, physical coordinates, virtual screen bounds, DPI factors, names, numbers, and counts. Unnumbered variables refer to the display the skin is mostly on; a number selects a specific display or device. See Monitor variables.
  • AddedEnvironment variables: The [%VariableName] syntax expands Windows environment variables and works with the updated skin syntax.
  • AddedOption inheritance: @Inherit allows both meters and measures to inherit options from other sections. It provides the functionality of MeterStyle for measures as well as meters.
  • AddedFormulas: Measure names and $Skin... and $Display... variables can be used without brackets in formulas throughout skins.
  • AddedInvisible updates: The Update option accepts a separate interval for invisible skins, such as Update=1000 | Invisible 10000. Invisible 0 suspends regular updates while invisible. Refresh and !Update still update the skin.
  • ChangedInvisible skins: Rainmeter skips unnecessary redraws when a skin is fully obscured and skips updates and redraws while its window is minimized. Visibility is reevaluated when the stacking order changes.
  • ChangedText file encoding: Reading and writing INI files detects and preserves UTF-8 encoding, including files edited with !WriteKeyValue. Rainmeter's own settings files use UTF-16.

Bangs and command line arguments #

  • AddedZoom bangs: !SetZoomFactor and !SetZoomFactorGroup set skin zoom factors. A value of 1.25 means 125%; Default restores the default zoom.
  • AddedUpdate interval: !SetUpdate changes a skin's visible update interval dynamically. The invisible update interval remains unchanged.
  • AddedVisibility override: !ForceEnableVisibleMode disables occlusion tracking for the targeted skin, allowing it to continue updating and drawing as visible.
  • AddedMeasure groups: !CommandMeasureGroup sends a command to measures in a group.
  • AddedDebug dialog: !Debug opens the Debug dialog. Optional parameters select Log, Display, Network, Plugins, or Skin, with an optional config name for the Skin tab.
  • AddedRestart: !Restart restarts Rainmeter. Rainmeter.exe /Restart replaces RestartRainmeter.exe, while existing skin actions that invoke RestartRainmeter.exe remain supported.
  • AddedLaunch before executing bangs: Rainmeter.exe [!Launch][!Bang][!Bang2] starts Rainmeter if necessary and then executes the bangs, even when Rainmeter was not already running.
  • AddedSkin bang namespace: !Skin:Load, !Skin:Unload, !Skin:Toggle, and !Skin:Edit provide aliases for the existing config commands. [!Skin:Unload *] unloads all skins. The !Skin: prefix also allows bangs that accept a skin target to place that target first.
  • AddedMeter and measure bangs: New !TextEdit:, !WebParser:, !NowPlaying:, and !Mouse: commands control their respective meters and measures. Section commands can use Group=GroupName as the section selector, or omit the selector when running in a matching section's action.
  • ChangedSetOption: The section argument of !SetOption can be omitted to set an option on the current section.
  • ChangedActivating skins: Activating an already loaded skin brings it to the front of windows sharing its z-position. Already active or inactive configs no longer produce redundant activation or deactivation warnings.

Meters and images #

  • AddedTextEdit meter: Meter=TextEdit provides text input directly in a skin, with single-line and multiline fields, selection, clipboard operations, undo, scrolling, placeholders, password masking, input filtering, and read-only mode. Actions receive the text through [$Input]; regular expression filter captures are available through [$Input:MatchN].
  • AddedTextEdit bangs: !TextEdit:Focus, :Dismiss, :Submit, :Select, :SelectAll, :SetText, :Clear, :Reset, :ScrollByLine, and :ResetScroll control input fields.
  • AddedSVG meter: Meter=SVG renders SVG files or inline SVG code. Attribute, Attribute2, and subsequent options change attributes on elements selected by ID, the root svg element, or all elements with *.
  • AddedString meter: StringAlign=Justify supports justified text.
  • AddedLine meter: LineJoin controls how line segments join.
  • AddedSystem images: SystemImage: image names support icons from the Windows system image list. FileView uses this support to supply file and folder icons.
  • FixedTransformationMatrix: Removing the option or setting it to an empty value clears the meter's previous transformation.
  • ChangedGraphics recovery: Skins can recover their rendering after graphics device loss.
  • ChangedShape errors: Error and warning messages identify the Shape option number.

Measures #

  • ChangedBuilt-in measures: ActionTimer, AdvancedCPU, AudioLevel, CoreTemp, FileView, FolderInfo, InputText, iTunes, PerfMon, Ping, Power, Quote, ResMon, RunCommand, SpeedFan, UsageMonitor, WindowMessage, and Audio (formerly Win7Audio) are built-in measures. Existing Measure=Plugin syntax for these measures remains supported.
  • AddedDragDrop measure: The Drag&Drop plugin is available as the built-in Measure=DragDrop. Existing plugin syntax remains supported; its former FancyRenderer option is removed.
  • AddedMouse measure: Measure=Mouse provides mouse coordinates and actions as a built-in measure.
  • AddedMouse click capture: !Mouse:StartCapture waits for the next click anywhere on any monitor and runs the matching button-up action with $MouseX$ and $MouseY$. Escape or !Mouse:StopCapture cancels capture. CaptureOverlayColor controls the overlay color and CaptureOverlayCursorName selects its system cursor.
  • AddedMouse actions: The new Mouse measure supports skin scaling and suppresses actions while a skin is selected or the pointer is over Rainmeter menus or dialogs.
  • AddedWebParser JSON: JsonPointer selects values from JSON responses without a regular expression. Child measures can select values relative to the JSON node selected by their parent. JsonPointer=1 enables JSON parsing without selecting a value.
  • AddedWebParser commands: !WebParser:UpdateData and !WebParser:ResetData provide direct commands for updating or resetting parsed data.
  • ChangedWebParser encoding: Local file:// URLs automatically detect text file encoding, such as UTF-8 or UTF-16, when using the default CodePage=0.
  • ChangedQuote encoding: The Quote measure automatically detects text file encoding, such as UTF-8 or UTF-16.
  • AddedLocale-formatted numbers: NumberConversionFormat=Locale lets String, Registry, and WebParser measures read numbers using the Windows locale's decimal and thousands separators, such as converting 1.234,56 to 1234.56.
  • AddedTime measure: TimeStampFormat supports ordinal dates, week-number dates, ISO week dates, and the %F, %g, %G, %u, %V, %z, and %Z codes. Time-zone offsets convert timestamps to UTC; %c, %x, and %X use the selected Windows locale and localized formats. Supported modifiers are handled, with errors for invalid or conflicting input.
  • AddedFileView filtering: ExcludeExtensions excludes listed file extensions. If both Extensions and ExcludeExtensions are defined, Extensions takes precedence.
  • AddedFileView commands: IndexUp and IndexDown accept an optional step count.
  • AddedUsageMonitor: Index=Count returns the number of instances. Index=Sum and Index=Average provide named alternatives for totals and averages. Process V2 instances can be grouped by process name, and the first collected value is returned before UpdateDivider restrictions apply.
  • AddedAudioLevel: OnAudioStartAction and OnAudioEndAction fire when audio playback starts or ends, allowing skins to change their update interval based on playback. Monitoring and these actions stop while the measure is disabled.
  • FixedAudioLevel: Reinitializes when the default audio device changes and avoids preventing automatic sleep when using USB speakers.
  • AddedNowPlaying covers: Added local .webp and .avif cover support and embedded cover support for Ogg Vorbis files.
  • AddedNowPlaying commands: New !NowPlaying: bangs provide playback and player controls, including position, rating, volume, shuffle, and repeat.
  • FixedRecycleManager: Emptying a large recycle bin no longer freezes Rainmeter while the operation completes.
  • ChangedRunCommand: Stopping a command terminates its descendant processes as well.
  • ChangedWiFiStatus: Where supported by Windows, connection quality and speed queries use an interface that avoids repeated location-access requests and excessive growth of Windows' capability access log.

Lua scripting and plugin support #

  • ChangedLua scripting: Uses LuaJIT 2.1, which is compatible with Lua 5.1.
  • AddedSetting options and variables: SKIN:SetOption, SKIN:SetOptionGroup, and SKIN:SetVariable set options or variables directly, with support for multiple name/value pairs supplied as tables. Meter and measure objects also support SetOption.
  • AddedUnicode strings: Unicode scripts have uc variants of string functions for matching, substitution, length, slicing, case conversion, reversing, and codepoint conversion. Scripts saved with a UTF-8 BOM are recognized as Unicode scripts, in addition to UTF-16 scripts.
  • AddedText files: SKIN:ReadTextFile and SKIN:WriteTextFile read and write text files with Unicode conversion. WriteTextFile defaults to UTF-8.
  • ChangedSkin position: SKIN:GetX() and SKIN:GetY() return logical coordinates.
  • FixedMeter dimensions: Lua meter SetW() and SetH() changes persist like SetX and SetY and trigger text remeasurement where needed.
  • FixedScript errors: Fixed memory corruption and crashes when Lua callbacks fail, improved callback and !CommandMeasure error reporting, and corrected handling of custom function calls and dofile.
  • AddedPlugin API: Plugins can read the skin's effective scale, DPI scale, zoom scale, transparency, click-through state, and draggable state. HandleSkinSettingChange notifies plugins when these settings change. Scaling support also applies to plugin coordinate, size, and font-size options.

User interface and recovery #

  • ChangedAbout and Debug: Version information is in a separate About dialog. The Debug dialog contains Log, Skins, Plugins, Display, and Network tabs. Manage and Debug remember their window sizes.
  • AddedDebug Skins tab: Added watches for evaluating expressions and executing actions, filtering measures and variables, and jumping to a meter or measure in the skin file. Values can be added to watches from their context menu or by double-clicking.
  • AddedRefresh on file change: The Debug Skins tab can automatically refresh the selected skin when its INI file, included files, or Lua scripts change. CTRL-R and F5 manually refresh the selected skin. Automatic refresh is disabled if repeated file changes cause too many refreshes in a short period.
  • AddedDebug Display and Network tabs: Display information includes monitor geometry and scaling. Network information lists interfaces, with an option to include virtual interfaces. Log, Display, and Network entries can be copied individually or together.
  • ChangedLogging: The in-memory log retains 50 entries instead of 20. Logging controls and log-file commands are available in the Debug dialog.
  • ChangedTray icon: Clicking the tray icon opens Manage; CTRL-click opens Debug. Running Rainmeter.exe while Rainmeter is already running opens Manage.
  • ChangedUpdate checks: Rainmeter checks for updates five minutes after startup and then once daily.
  • AddedContext menu shortcuts: Holding Shift changes Exit to Restart in the Rainmeter context menu, and Refresh skin to Focus skin in a skin context menu. Focus skin raises the skin within its current z-position. Skin menus also include Debug skin.
  • RemovedContext menus: Removed the Game Mode and Logging submenus from the Rainmeter context menu. Game Mode remains available in Manage; logging controls are in Debug.
  • AddedSkin discovery: Changes to the Skins folder are detected automatically. Rainmeter rescans the skin list when opening a context menu or activating Manage, and checks for newly added skins when activating a config.
  • ChangedDialogs: Dialogs support high-DPI rendering and positioning across monitors. Browsing for files and folders uses modern Windows dialogs. Application, installer, and skin tree icons have been updated.
  • AddedCrash dumps: Crash dumps are saved in Crashes\ under the Rainmeter settings folder. Dumps older than one week are removed automatically and can be included when reporting crashes.
  • AddedSafe Start recovery: After detecting two crashes within five minutes, Rainmeter prompts to start in Safe Start mode. To trigger Safe Start manually, hold CTRL-SHIFT for one second during startup.
  • ChangedTranslations: Updated interface translations and made Skin Packager and Skin Installer dialogs translatable. The Bengali translation has been removed.

Skin Packager #

  • AddedLoad previous: Restores the settings used when a skin was last packaged, including name, author, layouts, plugins, header image, and output folder. Hold Shift to delete entries from the menu. See Skin Packager.
  • AddedPlugin selection: Selecting one plugin DLL automatically looks for the other architecture by swapping folder names such as 32bit and 64bit.
  • AddedBack button: Returns to the previous packaging step without starting over.
  • ChangedPackage options: Removed the minimum Windows version option. Component dialogs are wider, show plugin paths more clearly, and open file browsers at the current selection.

Other fixes #

  • FixedMeasures: Fixed potential freezes and crashes in WebParser, NowPlaying, and RecycleManager.
  • FixedContainers: Empty Container values no longer resolve to unnamed meters and unintentionally clip other meters.
  • FixedSkin fading: Refreshing a skin during a fade no longer leaves it partially transparent. Starting a new fade while another is running no longer makes it jump to its end value.
