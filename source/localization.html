Rainmeter localization

Rainmeter supports displaying many items of its user interface in the local language selected by the user. These items include: the Rainmeter installer, the Manage interface, the About interface, the New Skin interface, various skin and application context menus, and various message boxes produced by the application. In order for these translations to be complete and correct, we need some help from you, the Rainmeter community.


How do you help?

Rainmeter is translated using the Weblate service. You can sign up for a free account, check the status of the language you want to translate, and make edits. Fully translated languages should will be marked 100%.

Please only translate languages that you speak very fluently. Rainmeter uses a lot of technical terms and it is very important that those terms match the Windows operating system. You can use the Microsoft terminology search tool to find the correct translations for technical terms.

If you don't want to use Weblate, you can also translate strings manually. You can find the translation files here. If you want to edit Finnish, for example, you could download the fi.ini file, make edits, and send it to us either via a GitHub pull request or through the Rainmeter forums.

After we've integrated your changes, they will be available for use in the next beta or release version of Rainmeter. This is a great help for the Rainmeter project and your fellow users in the Rainmeter community, and your effort is greatly appreciated!
